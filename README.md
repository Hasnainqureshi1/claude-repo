# claude-repo

Resources and tooling to help developers build web interfaces that look designed, not templated.

> **Status:** early stage. I am building this in the open as a solo maintainer. Expect things to change quickly.

## Why this exists

Most websites built today look alike. Same hero section, same card grid, same default fonts and colors. Many developers are great at code but have no design background, so they reach for the same templates and component kits every time.

This project tries to fix that by giving developers practical design guidance they can apply directly in code, so their sites end up with a clear identity instead of a generic look.

## Who it is for

- Developers and freelancers who do not have a designer on the team
- Small teams that want their product to stand out visually
- Anyone building with React, Next.js and Tailwind who is tired of the default look

## What is planned

- [ ] Design principles written for developers (typography, spacing, color, layout, motion)
- [ ] Reusable patterns and components with real design decisions behind them
- [ ] Before and after examples that show generic vs distinctive design
- [ ] Prompts and guidelines for using AI coding tools to get better design output
- [ ] Documentation and examples that are easy to copy and adapt

## Tech

Built mainly with TypeScript, React and Next.js. Details will be added as the first release takes shape.
